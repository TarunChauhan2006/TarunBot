# 🤖 Tarun Bot

An advanced AI chatbot built using **FastAPI + React + LLM (Groq/Ollama)**.

## 🚀 Features
- 💬 Real-time AI chat
- 🧠 Conversation memory (SQLite)
- 🎙 Voice input support
- ⚡ FastAPI backend
- 🎨 Modern React UI (Vite)
- 🔌 API-based LLM integration (Groq)

## 🛠 Tech Stack
- Backend: FastAPI, Python
- Frontend: React (Vite)
- Database: SQLite
- AI: Groq / Ollama (Llama3)
